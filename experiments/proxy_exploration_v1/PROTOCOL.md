## 并行与共同设置

六个组合各用一张空闲 GPU，统一锁获取失败则排队。同一组合的阶段二、三和五个适应分支按依赖顺序执行。GPU 实际编号由统一入口分配。seed 42、Gaussian A/零 B 的 q/v LoRA，r=8、alpha=16、dropout=0；底模和 tokenizer 沿用已核验 v6。

每个数据集先固定 1,344 个内容去重 ID，同一数据集的两个模型共用 ID。沿用历史五段：备用前缀 32、建池/实验一 256、独立梯度诊断 256、适应 500、最终评测 300。Dolly 沿用已执行的分割；其他两套清单在读分数前生成并冻结。前缀保留备用，主实验从 Source 状态开始，无公共预热。

## 实验一

逐组核对输入、底模 CE、Source 预测、模板/token 指纹与缓存身份。每组对共同的 256 题按各自模型的底模 CE 排四分位，各 64；并列按 source_index 排。Dolly/GeoSignal 用固定 ROUGE‑Lsum，GSM8K 用固定提取器 EM，均×100。报告四档、Q1−Q4、独立组 bootstrap 95% 区间（10,000 次，seed 421114）、长度、上下文、空答和生成上限。六组完整报告，人工可接受率待单独评价。

## 实验二

每组从 256 条 history 取最低 CE 的 64 条和均匀随机 64 条，随机种子固定，允许重叠并列出重叠数。两池共用同一 Source/LoRA 初始化。

对原始未加权输入 CE 求所有 LoRA 参数梯度，包含零 A 梯度块；记录数值有限性、参数顺序和范数。低 CE 池绕过 TLM 高 CE 门控求梯度是本方法的显式新增步骤。分别未中心化 SVD，取秩 5，保存 U、奇异值和池 ID。两池作同一固定半池拆分，计算 5 维子空间重合度，报告组内余弦和能量谱。

对独立 diagnostic 的 256 题，在同一状态计算梯度，分别测两池的 ‖Uᵀg‖/‖g‖，零梯度单列。结合该状态 Source 的现有回答指标描述关联。保留率解释为几何覆盖，生成效用由实验三检验。

### 困惑度信号与回答质量的交叉分组

六组统一在独立 diagnostic 的 256 题内部按各自冻结模型的输入 CE 排四分位，最低 64 题为低困惑度组，最高 64 题为高困惑度组。并列按 source_index 打破。两端共 128 题按 Source 回答质量再分组，中间两档保留原始诊断数据。

| 分析组 | 操作定义 | 关注的问题 |
|---|---|---|
| 低 CE、回答好 | 最低四分位且回答正确/可接受 | 低困惑度信号与较好回答相符的样本 |
| 低 CE、回答差 | 最低四分位且回答错误/不可接受 | 低困惑度信号失准的重点样本 |
| 高 CE、回答好 | 最高四分位且回答正确/可接受 | 难预测输入但仍能答好的样本 |
| 高 CE、回答差 | 最高四分位且回答错误/不可接受 | 难预测输入且答得差的样本 |

四组分别报告。主比较为低 CE、回答好与低 CE、回答差；高 CE 内的好/差对比为补充。先列实际分母、长度、上下文比例和可取得的题型分布，梯度差异按当前样本构成解释。

GSM8K 沿用固定答案提取器 EM，单列提取失败及预固定抽查。Dolly、GeoSignal 对两端 128 条回答使用统一盲评标准，人工判为可接受、不可接受或未决并给出理由。两模型 × 两个文本数据集共新增 512 条诊断回答的评价预算。评审题包隐藏模型、CE、四分位、梯度和自动分数；先冻结判定再联接梯度分析。未决单列，未完成评价的组标记待评。ROUGE 分数或重复规则不能直接代替人工质量标签。若以后使用模型辅助评价，须另行登记评价来源。

每个好/差比较先报告全量组内与组间余弦、原始梯度范数、未中心化 SVD 累积能量。需要比较谱集中程度时，用固定 seed 42 从两组各抽 m=min(n好,n差) 条，保留入选 ID；随机抽样不依梯度结果。若分析前 5 方向，两组共同使用 r=min(5,m)。m<2 时组内相似度标记样本不足，零梯度和未决另计。不因少数类不足调整 CE 阈值或重新挑题。

同样汇总各组在历史低池子空间和随机池子空间上的梯度保留率。两个 U 均仅由 history 输入构建，diagnostic 的 CE、质量标签和梯度不参与建池。重点检查低 CE 回答好组是否比低 CE 回答差组更相关、更集中、在无标签低池 U 内保留更多，原始分布和反向结果完整保留。质量分组自身的 SVD 只用于描述，不用于实验三更新。

本修订复用已计划采集的 diagnostic 梯度，新增分组统计、相似度热图、累积能量曲线和分组保留率表，实验三采用下文六条件。

## 实验三

六条件为 Source、完整普通更新 plain、固定 A 的普通更新 plain_b、随机池投影 random、低池投影 low、固定 A 的同幅度对照 matched。五条适应分支从同一初始 LoRA 和空优化器状态开始，用同序 500 条输入，每访问一次作同样的底模 CE>3 门控与 0.1 exp(baseCE−3) 权重计算。

plain 更新 A+B。plain_b 对普通 AdamW 候选位移清零 A 块，仅应用 B 位移。low/random 在投影前后显式清零 A 位移，防止数值误差泄漏。matched 先清零其自身普通候选位移的 A 块，再沿剩余 B 方向匹配 low 实际范数。所有分支仍维护相同参数布局的 Adam 状态，梯度裁剪及门控规则一致；每分支终点记录 A 位移，固定 A 分支要求精确为零，恢复检查点也绑定冻结参数索引。

预先固定各比较的解释。low 对 random 检验池选择，low 对 plain_b 检验在相同 B 参数范围中使用低池约束的总体作用，low 对 matched 检验相同步长及 B 参数范围下的方向作用。plain_b 对 plain 描述固定 A 的效果。low 对 plain 和 Source 报告整体收益。
主实现拟沿用 AdamW（betas .9/.999、eps 1e−8、weight decay 0）、梯度裁剪 1、batch 1、cosine/10% warmup、总长度 500。Dolly/GeoSignal lr=5e−5，GSM8K lr=1e−6，FP16 底模/FP32 LoRA。每步先计算各自 AdamW 候选参数位移 Δ，投影组实际写回 UUᵀΔ。准确记录为“优化器步长投影”，区别于直接投影梯度再执行 Adam。

先完成低池组，保存每个访问位置的实际位移范数。幅度对照沿其自身普通 AdamW 位移的 B 块方向，匹配同位置低池组范数；目标为零时应用零位移。按写回参数后的范数判断匹配，正目标相对误差容限为 0.001，零目标要求实际位移为零。跳步、零候选或舍入导致无法匹配时记录位置、原因和绝对/相对误差。Adam 历史状态照常推进，实际应用的参数位移决定下一步计算。本次采用 proxy-e3-six-adam-step-v3。

五组终点各生成共同 evaluation 的 300 题，Source 预测经核验复用。固定 greedy 和 512 新 token 上限。分别计算低池相对完整普通、B-only 普通、随机和幅度组的同题配对均差及 bootstrap 区间，并列相对 Source 差值。所有种子、组别、零差和反向结果一起报告。

## 启动前验证与产物

1. 统计单元测试覆盖四分位并列、合法分数及分割互斥。小张量检查正交基、投影和实际参数位移/幅度匹配。
2. 真实短预检采用 proxy-six-preflight-v3，每组合共 16 次访问。最长实际训练输入另作一次原始 CE 梯度检查。门控通过且底模 CE 最高的适应输入，分别进行完整普通、B-only 普通、加权投影及 B-only 同幅度更新各 4 次，学习率沿用正式设置。五维预检基由最长输入的 B 梯度与四个 B 坐标方向构造，专用于验证路径并丢弃。检查有限梯度与优化器状态、各分支至少两次有效更新、Source 重放、初始化恢复、冻结基座、投影残差不超过 0.001 及同幅度误差。预检状态不带入正式实验。
3. 每 25 次访问保存参数、优化器、调度、GradScaler、RNG、游标与指纹，使用原子检查点。预测逐题记录并支持明确的续算恢复。
4. 六组 CPU 分析单独登记请求，GPU 阶段每组合独立请求、完整 commit/代码/数据/模型合同指纹，plan 后由服务器独立会话启动。五条分支每组合共 2,500 次适应访问和 1,500 次新生成。六组修订预算为 15,000 次访问和 9,000 次新生成，较原预算增加 25%，须在新请求及执行授权中明确，另计梯度采集与短预检。
5. 交付六组实验一总表、梯度池与独立诊断表、四类质量分组计数及标签来源、等量抽样 ID、梯度相似度热图/谱/保留率、六组×六条件更新表、逐题预测及配对差、实际步数/跳步/投影误差/幅度匹配误差、时间显存记录和 Issue 交接。各阶段执行与质量状态分别记录。

## 与 Lifelong 的关系及审阅核验

本探究从 Lifelong 的可靠样本梯度结构假说出发，检验 LLM 输入 CE 的可靠性、目标域历史输入梯度结构及固定子空间的更新收益。这里采用源模型参数状态下的目标域 history 输入估计子空间，未中心化分解并投影 AdamW 候选位移。原方法的在线追踪、输出熵信号和优化器路径与本实验不同，结果按上述探究定义解释。

服务器只读核对显示六组各 5,000 条 Source 均有 metric、original_prompt_sha256、original_prompt_tokens、used_prompt_tokens、input_truncated，缺失数为零。两组 GSM8K 均有 extracted_answer，全量空值分别为 Llama 42、Qwen 44；这是全量缓存核对，诊断集失败数仍按实际入选 ID 统计。代码对缺字段显式报错。Dolly 当前规则重新生成的全部五段 1,344 个 ID 与旧试点 split.json 逐一一致。质量分析 CLI 已经持有输出锁并绑定身份。四分位 bootstrap 按固定分组成员解释为条件区间。
