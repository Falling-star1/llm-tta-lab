## 2. 两种适配面

四个基线在视觉 TTA 里都改"归一化层仿射参数"或"全部参数"。文本 LLM 上没有 BatchNorm，因此我们固定两种适配面，**同一个方法的所有组必须用同一种**：

| 适配面 | 可训练对象 | 新参数 | 用于 |
|---|---|---|---|
| `norm_gamma_only` | 所有 `*layernorm.weight` / `*norm.weight`（每层 2 个 + 最终 1 个），FP32 | 0 | Tent |
| `lora_qv` | `q_proj` / `v_proj` 的 LoRA，r=8、alpha=16、dropout=0、A 高斯初始化、B=0 | 有 | EATA |

可训练量（`run.py` 内有 assert 校验）：

| 模型 | gamma 个数 | LoRA 参数 |
|---|---:|---:|
| Llama-3.2-3B-Instruct | 175,104（73 × 3072） | 2,293,760 |
| Qwen2.5-3B-Instruct | 149,504（73 × 2048） | 1,843,200 |

RMSNorm 没有 beta、也没有 running statistics，因此 `norm_gamma_only` 只覆盖了 Tent 的一半（affine 部分），**不包含"用目标批统计量替换源统计量"那一步**。这是与论文的已知偏离，必须随结果一起报告。

## 3. 适应与评测流程（offline）

每个数据集独立进程、独立初始化的 adapter、seed=42：

1. 加载基础模型（FP16、`attn_implementation="sdpa"`、梯度检查点、`model.to("cuda:0")`，不用 `device_map`、不量化）；
2. 5000 条冻结 Source 生成 + 评分，写 `source.jsonl`；
3. 对全部 5000 条无标签输入依次更新，写 `adaptation*.jsonl`；
4. 用适应后的参数对 5000 条统一生成 + 评分，写 `tent.jsonl`（EATA 的 manifest 里该块改名为 `eata`，文件名不变）。

该流程是 offline，不与"逐条先更新后评分"的 online 结果混表。

### 3.1 输入与生成

| 项 | 值 |
|---|---|
| 输入编码 | 只用 `instruction` + `input`（`run.py:142`），参考答案只用于评分 |
| 输入截断 | 固定尾部截断，`cutoff_len=4096` |
| 适应前缀 | 模型自己贪心生成的前 **80** 个 token（`ADAPT_MAX_NEW=80`） |
| 评测生成 | **512** token（`EVAL_MAX_NEW=512`），greedy，`do_sample=False`，`num_beams=1`，`repetition_penalty=1.0` |

80 是适应前缀预算，512 是评测预算，**不能混用**。GSM8K 给 128 时 EM 从 0.75 掉到 0.0625。

### 3.2 熵（Tent 与 EATA 共用）

| 项 | 值 |
|---|---|
| 精度 | FP32（`logits.float()` 后 `log_softmax`） |
| 底 | 自然对数（nats） |
| 词表 | 全词表（128,256 / 151,936），无 top-k、无截断 |
| 位置 | 只取 continuation 区间，prompt 不参与 |
| 掩码 | 排除 prompt、PAD、以及第一个 stop token 或 pad token 及其之后全部位置 |
| 聚合 | 先按样本对有效位置取均值，再对 batch 取均值 |

## 4. 各方法的冻结口径

### 4.1 Tent

| 项 | 值 |
|---|---|
| 适配面 | `norm_gamma_only`（gamma 转 FP32） |
| 损失 | batch 内样本熵的算术平均 |
| 优化器 | Adam，betas=(0.9,0.999)，eps=1e-8，weight_decay=0 |
| 学习率 | 1.5625e-5 |
| batch | 2 |
| 轮次 | 1 epoch，每个 batch 一步 |
| 筛选 / 重置 / 早停 | 都没有 |
| 检查点 | 每 25 步存 `ckpt.pt`，支持按 journal 行数续跑 |
| 健全性 | 梯度范数 nan 或 ≤0 直接抛错（不跳过） |

### 4.2 EATA

| 项 | 值 |
|---|---|
| 适配面 | `lora_qv` |
| 损失 | 选中样本上的 `mean(H · exp(E0 − H))`（式 3 权重） |
| Fisher 抗遗忘项 | 代码已实现（式 7–9），但 `--fisher 0` → **实际未启用** |
| 优化器 | Adam，betas=(0.9,0.999)，eps=1e-8，weight_decay=0 |
| 学习率 | 5e-5（GSM8K 1e-6） |
| batch | 1 |
| 熵阈值 E0 | `0.4 · ln(V)`，V 取 `lm_head` 行数：Llama 4.70、Qwen 4.77 |
| 冗余度阈值 d_margin | 两套口径：`1.0`（早期组）与关闭（`lora2_*` 组，`--d-margin 0`） |
| 退化保护 | 整批被筛掉或梯度范数 ≤0 时跳过该步并计数，不抛错 |
| 检查点 | 每 25 步 |

**d_margin 的处理**（关键，别踩）：

- 式(5) 的判据是 `|cos(p_i, m)| < d_margin`，`m` 是历史样本 softmax 概率的 EMA（α=0.1）。
- 输出塌向同一方向时 `cos` 会被 float32 上舍入到 1.0（甚至 1.0000001），`|cos| < 1.0` 恒假，整批被筛掉 → 不更新、无日志。
- 所以 **`d_margin=1.0` 不等价于关闭**；关闭必须用 `<=0`（代码映射为 `None`）。
- 两套口径按分组标注，但对比时视为同一条件直接比分数（与"跨模型跨论文比分数"同一性质）。

## 5. 与论文的已知偏离

逐条记录，随结果一起报告，不隐藏：

| # | 偏离 | 原因 |
|---|---|---|
| 1 | Tent 只更新 gamma，不更新 beta，也不替换归一化统计量 | RMSNorm 无 beta、无 running stats；`norm_gamma_only` 是论文设定的缩减变体 |
| 2 | Tent 学习率 1.5625e-5、batch 2 | 文本任务 + 3B 模型重新标定，非论文值（Adam 1e-3 / BS 128~200） |
| 3 | EATA 的 Fisher 抗遗忘项未启用 | `--fisher 0`；proxy 样本池尚未构造 |
| 4 | EATA 的熵阈值把 C 换成词表 V | 论文 C = 模型输出空间；换成 V 是尺度上的直接对应，但论文只在 C∈{10,1000} 上调过 0.4 |
| 5 | 样本级熵是"有效位置熵的平均"，不是单一 V 维分布的熵 | 语言模型每个位置一个分布；阈值语义随之改变 |
| 6 | 式(5) 用了 `abs`（与官方代码一致，论文式 5 无 abs） | 概率向量非负时 abs 是空操作；保留代码写法以对齐官方实现 |
| 7 | 两套 d_margin 口径并存 | 早期 1.0 口径导致冻结，改关闭后重跑，旧组保留 |

## 7. 通过条件

**预检**：真实梯度与参数变化、基础权重不变、长输入可运行、adapter / 优化器 / RNG 恢复与继续一步逐元素一致。

**正式运行**：完整 `run_manifest.json`、全部指定样本、逐条预测、指标与异常计数、撞上限统计、耗时。

**质量**：分数下降也如实登记。`status=PASS` 只表示工程执行完成，**不表示方法有效**——例：Tent 在 llama3b/Dolly 上 0.3333→0.0347 也是 PASS。
