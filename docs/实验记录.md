## 4. EATA 式(5) 的冻结机制（负结果，需长期保留）

`eata_select`（`local_repro/eata_text/eata_alg.py:96`）的冗余度筛选是 `|cos(p_i, m)| < d_margin`，`m` 是历史样本 softmax 概率的指数滑动平均（α=0.1）。

- 当模型输出塌向同一方向（峰值概率 ≳0.95）时，`cos` 在 float32 下会被上舍入到 1.0 甚至 1.0000001，`|cos| < 1.0` 恒假 → 整批被筛掉 → 不 backward、不 step、无任何日志。
- 因此 **`d_margin=1.0` 不等于关闭式(5)**；关闭要用 `d_margin<=0`（代码映射为 `None`）。
- 观测：`llama3b/dolly` 用 1.0 时 4067/5000 个 batch 被整批筛掉；`llama3b/geosignal` 在 step 1964 出现同一冻结（`eata_alg.py` 注释记录）。
- 官方 EATA 代码默认 `d_margin=0.05`（ImageNet）/ `0.4`（CIFAR-10），论文与官方代码都没有讨论这种塌缩退化。

**模型恢复是稳定性的主要来源**：`reset` 次数 llama/dolly 28、llama/gsm8k 152、qwen/gsm8k 201（0.1%~8% 的步）。SAM 每步只做一次 `Θ+ε` 邻域前向，真正把参数拉回 source 的是 recovery，与官方 `sar.py:102` 硬编码 `if ema < 0.2` 的行为一致。

**需记录的偏差：reset 阈值在本任务上偏激进。** `reset_e0 = 0.072·E0 = 0.339`（llama）/ `0.344`（qwen）。论文的 `e0=0.2` 对应典型熵 1~2 nats、触发罕见；我们实测逐样本熵 0.2~1.5 nats，`0.339` 落在分布中段，故 8% 的步触发 reset。这**既可能是增益被压制的原因，也可能是阻止塌缩的原因**，本轮数据无法区分。要判定需扫 `--reset-ratio`（0.02 / 0.072 / 0.2），属新一轮实验。

其余已知偏差：`rho` 用相对量 `2e-4·‖θ‖`（llama 0.0354 / qwen 0.0794），官方 0.05 不可照搬；reset 时清 EMA（按论文 Algorithm 1，官方 `sar.py:52` 会写回旧 EMA 并连续多步反复 reset）；第二次前向用 teacher-forcing 不重新解码；优化器沿用项目协议 Adam。

### 8.3 SAR reset 比例敏感性

SAR 的模型恢复阈值 `reset_e0 = reset_ratio × E0`，论文的 `e0=0.2` 与 `E0=2.76` 给出比例 `0.072`。正式结果用这个换算值（§8.2）。为了说明这个选择的影响，另外跑了一轮 `--reset-ratio 0.02`（六组全跑，其余条件完全相同，`reset_e0 = 0.0941 / 0.0955`）。

**这不是选优实验**，是为了如实报告一个论文未公开、由我们自行换算的参数会把结果带到哪里。正式基线固定为 `0.072`。

| 模型 | 数据集 | 0.072 Δ | reset 次数 | 0.02 Δ | reset 次数 |
|---|---|---:|---:|---:|---:|
| llama3b | dolly | **−0.0059** | 28 | −0.0915 | 1 |
| llama3b | geosignal | −0.0024 | 1 | −0.0025 | 0 |
| llama3b | gsm8k | −0.0016 | 152 | +0.0050 | 5 |
| qwen3b | dolly | +0.0396 | 3 | **+0.0791** | 0 |
| qwen3b | geosignal | +0.0060 | 1 | **+0.0361** | 0 |
| qwen3b | gsm8k | −0.0010 | 201 | +0.0052 | 4 |

两轮均无塌缩，`quality` 全部 `OK`（0.02 轮唯一回答 4797~5000）。

**观察**：reset 频率是「稳定性 ↔ 增益」的旋钮，且不同格的最优点相反。

- `llama3b/dolly` 需要 reset：降到 0.02 后从 −0.0059 恶化到 −0.0915（仍未塌缩，但明显受损）。
- `qwen3b/dolly` 与 `qwen3b/geosignal` 需要少 reset：0.02 下增益回到 Tent 水平（+0.0791 vs Tent +0.0767；+0.0361 vs +0.0345）。
- `llama3b/gsm8k` 与 `qwen3b/gsm8k` 同样被 reset 拖累：152 / 201 次 reset → −0.0016 / −0.0010；降到 5 / 4 次 → +0.0050 / +0.0052。

因此**不存在一个全局最优阈值**，而 0.072 在 `Σ|Δ|` 上更小（0.0565 vs 0.02 轮的 0.2194），主要因为 `llama3b/dolly` 的 −0.0915 单独就占了 42%。引用时需同时给出两轮数据，不能只报更好的那一轮。

未继续向上扫（0.2 等）：`0.2·E0 = 0.94` 高于实测熵中位，会近乎每步 reset、参数被钉在 Source，结果可预测且对基线无意义。
