## 4. EATA 式(5) 的冻结机制（负结果，需长期保留）

`eata_select`（`local_repro/eata_text/eata_alg.py:96`）的冗余度筛选是 `|cos(p_i, m)| < d_margin`，`m` 是历史样本 softmax 概率的指数滑动平均（α=0.1）。

- 当模型输出塌向同一方向（峰值概率 ≳0.95）时，`cos` 在 float32 下会被上舍入到 1.0 甚至 1.0000001，`|cos| < 1.0` 恒假 → 整批被筛掉 → 不 backward、不 step、无任何日志。
- 因此 **`d_margin=1.0` 不等于关闭式(5)**；关闭要用 `d_margin<=0`（代码映射为 `None`）。
- 观测：`llama3b/dolly` 用 1.0 时 4067/5000 个 batch 被整批筛掉；`llama3b/geosignal` 在 step 1964 出现同一冻结（`eata_alg.py` 注释记录）。
- 官方 EATA 代码默认 `d_margin=0.05`（ImageNet）/ `0.4`（CIFAR-10），论文与官方代码都没有讨论这种塌缩退化。
