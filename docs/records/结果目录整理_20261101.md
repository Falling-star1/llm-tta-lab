## 3. 保留的软链接

历史 JSON 里的引用全是绝对路径（`/data/chuwenjing/results/<名字>/…`），移动后会在原位置留 0 字节软链接，保证旧路径仍可解析：

| 软链接 | 指向 | 引用方 |
|---|---|---|
| `tlm_offline_v6_preflight` | `preflights/…` | `tlm_offline_v6_ready` controller.json、`tlm_qwen_dolly_recovery_v6` launch.json |
| `tent_formal_v3_6gpu` | `archives/tent_lora_b1_v3_20261020_001210` | `archives` 六个 manifest 的 `result_root`、两个 recovery 文件 |
| `tlm_dolly_followup` | `diagnostics/…` | `dolly_gbb_v2/*/config.json` |
| `source_smoke` | `preflights/…` | `tent_offline_smoke` 四个 manifest |
| `tent_full_preflight`、`tent_full_preflight_3gpu` | `preflights/…` | `tent_full_preflight_3gpu_det` manifest |

六条旧绝对路径已逐条验证可解析。`archives/` 是 `tent_paper` 与四个在跑实验的 source 复用源，**任何时候都不能动**。
