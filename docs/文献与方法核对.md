## 1. Tent

| 项 | 论文 | 官方代码 | 我们的实现 |
|---|---|---|---|
| 更新对象 | 所有归一化层的仿射参数 γ 与 β（`<1%` 参数） | `tent.py` 只对 `nn.BatchNorm2d` 开梯度，收集 `weight`(scale) 与 `bias`(shift) | 只训 RMSNorm 的 gamma（`norm_gamma_only`），**无 beta** |
| 归一化统计量 | 丢弃源统计量，改用目标批统计量 | `track_running_stats=False`，`running_mean/var=None` | **无对应步骤**（RMSNorm 无 running stats） |
| 损失 | 单样本熵 `H(ŷ) = −Σ_c p log p`，对 batch 求平均 | `softmax_entropy(x).mean(0)`，熵对类别维求和 | 每 token 全词表熵 → 按样本对有效生成位置取均值 → 按 batch 取均值 |
| 优化器 | Adam，BS=128，lr=1e-3（CIFAR）；SGD+momentum，BS=64，lr=2.5e-4（ImageNet） | 示例 Adam lr=1e-3、BS=200（`cfgs/tent.yaml`） | Adam lr=1.5625e-5、batch=2 |
| 适配 token | 不适用（图像） | 不适用 | 模型自生成的 80 个 token（依 TLM 附录 C.2） |

结论：`norm_gamma_only` 是**论文设定的缩减变体**，只覆盖 affine 那一半，且把 γ 与 β 缩成 γ。写作时必须说清，不能说"这就是 Tent 的文本版"。

## 2. EATA

| 项 | 论文 | 官方代码 | 我们的实现 |
|---|---|---|---|
| 式(3) 熵筛选 | `S^ent = exp[−(E−E0)] · I{E<E0}` | `filter_ids_1 = entropys < e_margin`；`coeff = 1/exp(E−E0)` | 同（`per_sample < e_margin`，`coeff = exp(E0−E)`） |
| E0 | `0.4 × ln C`，C = 任务类别数 | `main.py` 默认 `0.4·ln(1000)`；类内默认 `ln(1000)/2−1`（残留值，实际被命令行覆盖） | `0.4·ln(V)`，V = `lm_head` 行数：4.70 / 4.77 |
| 式(5) 冗余筛选 | `S^div = I{cos(f_Θ(x), m^{t−1}) < ε}`，**无绝对值** | `torch.abs(cos) < d_margin` | 同代码（带 abs） |
| ε / d_margin | 0.4（CIFAR-10）/ 0.05（ImageNet） | 默认 0.05 | 两套口径：1.0（早期组）与关闭（`lora2_*` 组） |
| m 的更新 | `m^t = α ȳ^t + (1−α) m^{t−1}`，α=0.1 | `0.9*current + 0.1*new.mean(0)` | 同 |
| Fisher 抗遗忘 | 式(7)(8)(9)，ω 为对角 Fisher，β = 1/2000 | `fisher_alpha=2000`，`fisher_size=2000`，硬伪标签 + CE 梯度平方 | 代码已实现，`--fisher 0` → **未启用** |
| 熵维度 | 输出空间 C（论文把 C 定义为 model output space） | `.sum(1)`，即 softmax 那一维 | 词表 V，逐位置后按样本平均 |

### 2.1 论文与官方代码的三处不一致（引用时必须注明出处）

| # | 论文 | 代码 | 影响 |
|---|---|---|---|
| 1 | β = **1/2,000**（两处均如此） | `fisher_alpha` 默认 **2000** | 量级差 4×10⁶。我们未启用 Fisher，暂不受影响 |
| 2 | 式(5) **无 abs** | `torch.abs(...)` | 概率向量非负时 abs 是空操作；作用在 logits 上才有意义 |
| 3 | E0 = 0.4·ln C | 类内默认 `ln(1000)/2−1`，命令行默认 `0.4·ln(1000)` | 生效值是命令行那个；类内默认是残留 |

### 2.2 式(5) 在文本上的退化（我们的发现，论文与代码均未讨论）

- 概率向量间 `cos ∈ [0,1]`；模型塌向同一方向时 `cos → 1`。
- float32 下不需要严格 one-hot：峰值概率约 0.95 以上时 `F.cosine_similarity` 已返回 ≥1.0（实测 p_max=0.9566 → cos=1.0；p_max=0.99999 → cos=1.0000001）。
- 此时 `|cos| < 1.0` 恒假 → 整批被筛掉 → 不 backward、不 step、无日志（官方代码同样静默）。
- **`d_margin=1.0` 不等价于关闭**：它恰好把筛选退化成"只拦完全同向"，平时几乎全放过，一旦塌缩才整批冻结。关闭必须用 `<=0`。
- 观测：`llama3b/dolly` 用 1.0 时 4067/5000 个 batch 被整批筛掉；`llama3b/geosignal` step 1964 出现同一冻结；gamma 面的 `full_paper_llama3b_geo` 用 0.05 时 250 步只反传 3 次。

### 2.3 E0 从 C 换成 V 的合法性

论文第 84 行把 C 定义为 "the model output space"，所以 C ↔ V 是**直接对应而非类比**：E0 必须与熵的上界 ln(输出空间大小) 同尺度，否则 0.4·ln(10)≈0.92 对 V=151936 的模型几乎筛不掉任何样本。

但两点必须注明：① 论文只在 C∈{10,1000} 上把 0.4 调过，外推到 1.5×10⁵ 无论文依据；② 我们的样本级熵是"有效位置熵的平均"，不是单一 V 维分布的熵，式(3) 的阈值语义在这一点上已偏离原义。

## 3. TLM

| 项 | 论文 | 官方代码 | 我们的理解 |
|---|---|---|---|
| 损失 | 输入困惑度最小化 `min S(x)·P(x;Θ)` | `compute_loss`：基座模型算 `sentence_ce` → mask + 加权 → 当前模型对 labels 的 KL | 同 |
| 监督对象 | 只能用输入 x，拿不到 ground truth y（第 109 行） | `self_supervised.py:79`：`labels = input_ids`（prompt 部分），response 被丢弃 | **不读参考答案** |
| 筛选 | `S(x)=λ·e^{[logP(x)−logP₀]}·I{P(x)>P₀}` | `mask = sentence_ce > threshold`，`coeff = lamb*exp(ce−threshold)` | 同 |
| 超参 | λ=0.10，P₀=e³（即阈值 3） | 字段默认 threshold=2.0、lamb=0.1；实验 yaml 用 3 / 0.1 | 以 yaml 为准 |
| 更新参数 | LoRA，r=8，作用在 W_q、W_v，A 高斯、B=0 | `lora_target: q_proj,v_proj`，`lora_alpha = rank*2 = 16` | 同 |
| 平均位置 | 逐 token NLL 在有效位置上平均（输入序列，不是生成位置） | `(token_logps*loss_mask).sum(-1)/loss_mask.sum(-1)` | 同 |

### 3.1 附录 C.2：TLM 作者自己怎么把 Tent/EATA 搬到文本

> "we adapt the Tent method to work with LLMs by leveraging the prediction entropy of the **80 tokens generated by the model**."

> "we adapt the EATA method by leveraging the prediction entropy of 80 tokens generated by the model to select samples … (with the hyperparameter **E₀ of EATA set to 0.4**). However, performing EATA updates on Llama2-13B-chat may result in out-of-memory errors. To address this issue, we reduce the number of tokens from **80 to 30**."

要点：

1. 80 token 的口径**来自论文作者**，不是我们自己定的；我们沿用。
2. 作者写的是 "E₀ set to 0.4"，**是 0.4 这个绝对值还是 0.4·ln C 的比例**，原文没说清。我们取 `0.4·ln(V)`（按 EATA 原文的公式），与作者的 0.4 是否一致无法从论文判定。
3. 作者没有讨论 d_margin（式 5），即 C.2 只描述了式(3) 的熵筛选。我们启用/关闭式(5) 都属于作者的描述之外的扩展。

### 3.2 关于"TLM 用了 labels"

`labels` 在代码里确实被读取（`trainer.py:223,232`），但 `self_supervised.py:79` 把 `labels` 赋成 `input_ids`（prompt 部分），参考答案从未进入损失。所以：

- **TLM 与四个基线一样不使用参考答案**；
- 两者的真正区别是**优化信号来源**：基线取模型自身输出分布（熵），TLM 取真实输入文本的似然；
- 早期文档里"TLM 原版用了 labels 而基线不许用"的说法**不成立**，已在本仓库更正。
