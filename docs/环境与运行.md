## 当前有效代码与运行入口

现行结果由 `local_repro/` 下的自建脚本产生（仓库里是只读快照）：

| 入口 | 用途 | 命令 |
|---|---|---|
| `local_repro/tent_paper/run.py` | Tent（`norm_gamma_only`） | `python tent_paper/run.py formal --model llama3b --dataset dolly_5k --gpu 0` |
| `local_repro/eata_text/run_eata_lora.py` | EATA（`lora_qv`） | `python eata_text/run_eata_lora.py formal --model llama3b --dataset dolly_5k --gpu 1 --d-margin 0` |
| `local_repro/eata_text/run_eata.py` | EATA（`norm_gamma_only`） | `python eata_text/run_eata.py formal --model llama3b --dataset dolly_5k --gpu 2` |

`--d-margin 0` 表示**关闭** EATA 式(5)；不要用 `1.0` 代替（模型塔尖时 `|cos|` 上舍入到 1.0，会静默冻结，见[实验记录](实验记录.md) §4）。

## 旧 7B 三卡包的运行方式（仅存档）

先与组员核对是否已有同一全量实验启动，登记 OUTPUT_DIR、PID 和 GPU；未确认前不要重复启动。三组预检已于 2026-10-18 19:48:30 通过，收据绑定固定代码与协议；配置、代码、设备布局或模型变化需重新预检。

在已有完整部署与有效预检收据的服务器上，协调三张空闲卡后执行（7B 三卡包，历史）：

```bash
cd /data/chuwenjing/tta_offline/tlm_tent_full_3gpu_det_bundle
nvidia-smi
nohup bash run_tent_full.sh run 0,1,2 >> full.log 2>&1 < /dev/null &
tail -n 30 full.log
```

`0,1,2` 是示例物理卡号，必须确认资源可用。保存日志开头的 OUTPUT_DIR。按每组 Source5000 → 适应5000 → Tent评测5000 运行；完成标志 `TENT_FULL_RUN=PASS`，同时核对完整 manifest、各数据集数量和产物，不能只看终端 PASS。

未部署的新服务器先由环境负责人取得固定 TLM 源码、离线依赖、模型和数据，核对 bundle 的固定路径再部署；不要直接套用上述运行命令。完整上传、preflight 与 resume 说明见[冻结包 README](../offline_tta/tlm_tent_full_3gpu_det_bundle/README.md)。GitHub clone 后须先运行仓库完整性检查，防止换行转换破坏哈希。

恢复前确认原进程已停止，使用原始完整 OUTPUT_DIR 作为 `resume` 最后参数；不要使用旧失败预检目录。失败保留日志、状态与检查点，不覆盖原结果或自行放宽断言。
