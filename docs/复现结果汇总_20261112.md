### 3.1 TLM 与论文的超参对照

来源：论文附录 C.2、`examples/train_lora/offline_ttl.yaml`、`src/llamafactory/train/ttl/trainer.py:214-261`；我们侧取 `resolved_config.json` 与 `tlm_loss.py`。

| 项 | 论文 / 官方仓库 | 我们（v6） | 一致 |
|---|---|---|---|
| LoRA target | `q_proj,v_proj` | `q_proj,v_proj` | ✓ |
| rank / alpha | r=8，alpha = rank×2 = 16 | 8 / 16 | ✓ |
| A / B 初始化 | A 高斯，B=0 | `lora_init: gaussian`，B=0 | ✓ |
| 优化器 | Adam，betas 0.9/0.999，eps 1e-8，wd 0 | 同 | ✓ |
| 学习率 | 5e-5 / 5e-5 / 1e-6（Domain / Instruction / Reasoning） | 5e-5（geo、dolly）、1e-6（gsm8k） | ✓ |
| batch / epoch | 1 / 1.0 | 1 / 1.0 | ✓ |
| scheduler | cosine，warmup_ratio 0.1 | cosine，warmup_ratio 0.1 | ✓ |
| max_grad_norm | 1.0 | 1.0 | ✓ |
| λ | 0.10 | 0.1 | ✓ |
| P0 | `e³`（等价于 CE 阈值 3） | `threshold=3.0` | ✓ |
| 损失归一化 | `Σ(kl·coeff·mask) / Σmask` | `weighted.sum() / mask.sum().clamp_min(1)` | ✓ |
| CE 对象 | 输入 token（labels = input_ids） | `input_cross_entropy(input_ids)` | ✓ |
| 截断 / 生成 | 4096 / 512，greedy，temperature 0 | 同 | ✓ |
| 精度 | bf16 | fp16 | ✗ 2080 Ti 不支持 bf16 |

除精度外逐项一致。因此 Llama GSM8K 上 0.13 的缺口不能用超参差异解释，只剩精度与 5000 步轨迹上的未知因素。

## 4. 失效组的机器证据

| 组 | 分数 | 撞 512 上限 | 实际反传 / 总步 | 适应熵 first → last |
|---|---:|---:|---:|---|
| Tent-LoRA llama3b geosignal | 0.0121 | 5000 / 5000 | 5000 / 5000 | — |
| Tent-LoRA llama3b dolly | 0.0005 | 5000 / 5000 | 5000 / 5000 | — |
| Tent-LoRA qwen3b geosignal | 0.0080 | 5000 / 5000 | 5000 / 5000 | — |
| Tent-LoRA qwen3b dolly | 0.0001 | 5000 / 5000 | 5000 / 5000 | — |
| EATA llama3b geosignal（d_margin 关闭） | 0.0122 | 5000 / 5000 | 5000 / 5000 | 0.5946 → 6.05e-07 |
| EATA llama3b dolly（d_margin 关闭） | 0.0184 | 4999 / 5000 | 5000 / 5000 | 0.2381 → 7.56e-07 |
| EATA llama3b dolly（d_margin=1.0，旧口径） | 0.0910 | 0 / 5000 | 933 / 5000 | 见实验记录 §4（式(5) 整批筛空） |
| EATA qwen3b geosignal（d_margin 关闭） | 0.0211 | 5000 / 5000 | 4994 / 5000 | 0.6548 → 3.90e-06 |
| EATA qwen3b dolly（d_margin=1.0） | 0.0366 | 5000 / 5000 | 5000 / 5000 | 0.6392 → 0.0114 |

撞上限 5000/5000 意味着每条回答都在 512 token 处被截断，ROUGE 分数只是「重复串与参考答案的重合度」。这些组的 PASS 只是工程状态。

`d_margin` 两套口径（1.0 与关闭）按同一条件处理，理由见 [实验记录](实验记录.md) §0 与 §4：1.0 在未塌缩时与关闭几乎等价，塌缩时会整批筛空。

## 5. 复现结论

- **TLM v6 是唯一在 Geography 上稳定提升的方法**：Llama +0.0534（论文 +0.0498）、Qwen +0.0470（论文 7B +0.0432），方向和幅度都对得上。
- **最大未复现项**：Llama GSM8K 的 TLM。论文 0.7756 → 0.9096（+0.1340），我们 0.7760 → 0.7798（+0.0038）。输入 token 已逐条核对（5000/5000 与官方处理器一致）、前 8 步梯度在 Llama 上逐值一致，所以不是输入或实现走错路，差异出在 5000 步轨迹上，尚无根因。
- **Dolly 全线未复现**：Llama Dolly 上四个方法没有一个为正；论文 TLM 在该组是 +0.0092，我们 −0.0926。
- **EATA 的塌缩只对上一半**：论文 EATA 在 Llama 的 Geo / Dolly / GSM8K 全是 0.003~0.009（全塌），我们 Geo / Dolly 塌（0.0122 / 0.0184）、GSM8K 不塌（0.7784）。Qwen 的论文 EATA 在 Geo / Dolly 是 0.21 左右（没塌），我们塌了——规模不同，不能当同一现象。
- **Tent-LoRA 整组作废**：geo / dolly 四组 5000/5000 撞上限，只有 GSM8K 两组（0.7804 / 0.8362）可读，且与论文 Tent（0.7726 / 0.8455）同量级。

## 6. 复现限制（必须随表一起引用）

- 环境是 RTX 2080 Ti + FP16，论文是 A800 + BF16；精度路径不等价。
- Qwen 是 3B，论文是 7B，两表之间不能做因果推断。
- 论文 Tent / EATA 只公开了「自生成 80 token 的熵」与 `E0 = 0.4` 两条；适配面、学习率、初始化未公开，官方仓库也没有这两个方法的实现。我们的 Tent-RMSNorm（RMSNorm gamma，lr 1.5625e-5）与 EATA-LoRA（q/v LoRA，lr 5e-5 / 1e-6）都是按本仓库 [复现协议](复现协议.md) §2 自定的，不是论文原始配置。其中 `E0` 口径差约 12 倍（0.4 vs 4.70）属已知未解冲突。
- TLM v7 content（Llama Dolly 0.3393）属于方法变体诊断，不能替换 v6 正式结果。
- 分数只代表本机这套 FP16 配置下的结果，不代表论文条件已复现。
